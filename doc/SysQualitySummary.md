프로젝트 정의서에서 제시한 핵심 기능 분석을 기반으로 대상 시스템에서 중요하게 고려해야 할 품질 요소 추정 및 정리하기

(1) 사용자가 원하는 기대치는?

가용성: 약 200명의 직원이 시스템을 이용하는데 불편함이 없어야 함

성능: 파일 검색 결과가 빠르게 표시되어야 함

사용성: 웹 브라우저만으로 간단히 파일을 업로드 및 다운로드 할 수 있어야 함

신뢰도: 실수로 삭제된 파일도 일정 기간 내에 안전하게 복구할 수 있어야 함



(2) 개발자 혹은 유지보수 담당자가 원하는 기대치는?

보안: 데이터 접근 및 전송 시 보안 유지를 통해 데이터 유출을 방지해야 함

유지보수: 새로운 기능이 추가될 것을 대비하여 코드가 간결하고 정형화 되어있어야 함




(3) 개발 조직의 관리자가 원하는 기대치는?

운영 효율성: 200명 규모의 사용자 계정을 생성, 삭제하고 사용자의 저장공간을 효율적으로 통제할 수 있어야 함

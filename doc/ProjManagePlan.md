# 📄 프로젝트 관리 계획서: 미니 드라이브 구축 프로젝트

1. 개요 (Introduction)
    1.1 문서의 목적
    본 문서는 조직 내 협업 활성화를 위한 클라우드 파일 공유 시스템인 '미니 드라이브'의 성공적인 개발을 위해 프로젝트의 목표, 자원, 일정, 조직, 품질 및 위험 관리 등 전반적인 관리 계획을 정의하고 가이드를 제공하는 데 목적이 있다.

    1.2 프로젝트 개요
    **프로젝트 명칭:** 조직 내 협업 활성화를 위한 클라우드 파일 공유 시스템 구축 (미니 드라이브)
    **목표:** 설치 없이 웹 브라우저 기반으로 동작하며, 중앙 집중식 파일 저장, 계층형 폴더, 버전 관리, 강력한 권한 및 공유 기능을 제공하여 업무 연속성과 효율성을 극대화한다.
    **제약사항:** 개발 기간과 비용, 인력 구성에 제한을 두지 않고 최고 수준의 가용성(99% 이상)과 성능(검색 2초 이내)을 달성한다.

    1.3 관련 문서, 용어 및 약어
    **JWT (JSON Web Token):** 사용자 인증 및 권한 인가를 위해 사용되는 토큰.
    **MSA (Microservices Architecture):** 향후 확장성(AI 검색, 공동 편집)을 고려해 시스템을 독립적인 서비스 단위로 분리하는 아키텍처.

2. 개발 계획 (Development Plan)
    2.1 프로세스 모델 및 개발 방법론
    **방법론:** 애자일(Agile) 스크럼(Scrum) 방법론 적용. 2주 단위의 스프린트(Sprint)를 통해 지속적으로 기능을 통합하고 피드백을 수용하여 품질을 높임.

    2.2 작업 분할도 (Work Breakdown Structure)
    **1.0 요구사항 및 설계:** 요구사항 분석, UI/UX 설계, DB 설계, 아키텍처 설계
    **2.0 인프라 및 환경 구축:** 클라우드 인프라 세팅, CI/CD 파이프라인 구축
    **3.0 백엔드 및 코어 로직 개발:** 회원 인증(JWT), 파일 업/다운로드, 계층형 폴더 구조, 버전 관리 시스템 구현
    **4.0 프론트엔드 개발:** 웹 UI 구현, 검색 및 공유 인터페이스 연동
    **5.0 품질 검증 및 배포:** 성능 테스트, 보안 모의 해킹, 최종 배포

    2.3 소요 자원 (Staffing, Cost)
    **인적 자원:** 기간과 예산 제한이 없으므로, 프로젝트 관리, 아키텍처, 백엔드/프론트엔드, DB, 보안, UI/UX 디자인 등 각 분야의 최고급 시니어 인력을 필요에 따라 무제한(초기 14명 규모)으로 투입.
    **물적/비용 자원:** 무제한 예산을 활용하여 고성능 클라우드 인프라(AWS/GCP), 최상위 보안 솔루션, 상용 DB 라이선스를 적극 도입.

    2.4 일정 계획 (Gantt Chart)
    총 6개월(24주)의 여유로운 일정을 통해 확장성과 안정성을 완벽히 확보함.
    1~4주차: 요구사항 확정 및 시스템 설계
    5~12주차: 인프라 구축, 코어 기능(파일 업/다운, 인증) 개발
    13~18주차: 심화 기능(검색, 버전 관리, 공유) 구현 및 통합
    19~22주차: 전면적인 QA, 보안 검증 및 부하 테스트
    23~24주차: 시스템 안정화, 사용자 교육 및 정식 배포

3. 조직 구성 (Organization)
    3.1 팀 구조
    PM(Project Manager)을 중심으로 기능별 조직(프론트엔드, 백엔드, 인프라/보안)이 유기적으로 협력하는 매트릭스 조직 구조를 채택함.

    3.2 책임 및 역할
    | 역할 | 담당 업무 |
    | :--- | :--- |
    | **PM** | 프로젝트 총괄, 이해관계자 소통, 일정 및 리스크 관리 |
    | **System Architect** | 시스템 전체 구조 및 클라우드(MSA) 설계 |
    | **Backend Developer** | API 개발, 버전 관리 로직, 검색 및 인증 기능 구현 |
    | **Frontend Developer** | 웹 브라우저 기반 UI/UX 구현, 사용자 인터랙션 개발 |
    | **Security/QA** | 데이터 암호화 구현, 시스템 성능(2초 이내 검색) 및 부하 테스트 |

4. 기술 관리 계획 (Technical Management)
    4.1 버전 관리
    **코드 관리:** Git과 GitHub/GitLab을 활용. 브랜치 전략으로 'Git Flow'를 채택하여 기능 개발, 릴리즈, 핫픽스를 엄격히 분리하여 안정적인 버전 관리를 수행함.

    4.2 형상 관리
    **인프라 및 환경 관리:** 인프라를 코드로 관리하기 위해 Terraform을 사용하고, 서버 환경의 일관성을 위해 Docker와 Kubernetes(K8s) 컨테이너 오케스트레이션을 도입함.

    4.3 기술 관리
    **이슈 트래킹:** Jira를 활용하여 스프린트 내 백로그 및 버그 현황을 추적함.
    **문서화:** Confluence 및 Swagger를 사용하여 API 명세서와 시스템 설계 문서를 실시간으로 최신화함.

5. 품질 관리 계획 (Quality control)
    5.1 품질 목표
    **가용성:** 업무 시간 내 99.9% 무중단 서비스
    **성능:** 대규모 동시 접속 시에도 파일 검색 결과 2초 이내 출력
    **보안:** 전송 및 저장 데이터 100% 암호화, JWT 기반 권한 통제

    5.2 검토 방법 및 주기
    **주기:** 매 스프린트(2주) 종료 시점마다 코드 리뷰 및 기능 시연(Review) 진행.
    **방법:** 동료 검토(Peer Review) 및 정적 코드 분석 도구(SonarQube)를 활용한 자동화된 코드 품질 검사.

    5.3 품질 관리 적용 기법
    TDD(테스트 주도 개발)를 도입하여 핵심 비즈니스 로직의 단위 테스트 커버리지를 80% 이상으로 유지.
    자동화된 CI/CD 파이프라인을 통해 통합 테스트 및 빌드 과정을 상시 모니터링.

    5.4 리스크 관리
    | 리스크 요소 | 대응 방안 |
    | :--- | :--- |
    | **대용량 파일 동시 처리로 인한 병목** | 오토 스케일링(Auto-scaling) 적용 및 비동기 분할 업로드(Chunk) 기술 도입 |
    | **외부 공유에 의한 보안 유출** | 외부 링크 유효기간(최대 7일) 및 비밀번호 설정 강제화 |

6. 개발 환경 (Development Environment)
    6.1 요구되는 소프트웨어 스펙
    **Language & Framework:** Java/Spring Boot (Backend), React/Vue.js (Frontend)
    **Database:** PostgreSQL (메타데이터), Elasticsearch (고속 검색엔진), Redis (캐싱)

    6.2 요구되는 하드웨어 스펙
    **서버/스토리지:** AWS EC2(고성능 인스턴스), AWS S3(대용량 오브젝트 스토리지 다중화)

    6.3 개발 공간 및 보안 요구사항
    **개발 공간:** 원활한 소통을 위해 애자일 전용 프로젝트 룸(물리적 공간) 구성.
    **보안 요구사항:** 개발 및 테스트 환경은 내부망(VPN)을 통해서만 접근 가능하도록 통제하며, 소스코드 유출 방지를 위한 DLP(데이터 유출 방지) 솔루션 적용.

    7.1 산출물 목록: 산출물 명, 생성 일자, 배포처
    | 산출물 명 | 생성 일자 (예정) | 배포처 |
    | :--- | :--- | :--- |
    | 요구사항 명세서 | 프로젝트 2주차 | PM, 개발팀 전체 |
    | 시스템 아키텍처 설계서 | 프로젝트 4주차 | 개발팀, 인프라팀 |
    | API 명세서 (Swagger) | 프로젝트 8주차 | 백엔드/프론트엔드 팀 |
    | 테스트 결과 보고서 | 프로젝트 22주차 | PM, QA팀 |

8. 기타 고려 사항
    * **유지보수 및 확장성:** 향후 문서 공동 편집 및 AI 검색 기능 추가를 위해 마이크로서비스 아키텍처(MSA) 기반의 결합도가 낮은 시스템 설계를 원칙으로 함.
    * 비용의 제한이 없는 만큼 개발자의 업무 피로도를 낮추고 생산성을 높이기 위한 최고급 장비(PC, 모니터) 및 휴식 환경을 적극 지원함.

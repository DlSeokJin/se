## 1. 서론

### 1.1 문서 목적 및 범위
본 문서의 목적은 소프트웨어학과의 프로젝트로 진행하는 '미니 드라이브 파일 공유 시스템' 프로젝트에 대한 테스팅을 수행하고 그 결과를 나타내는 데에 있다.
본 문서에서는 위 프로젝트의 테스트 기준, 테스트 범위, 테스트 케이스와 테스트 결과를 명시한다.

### 1.2 프로젝트 개요
사용자가 웹 브라우저를 통해 별도의 설치 없이 다양한 형식의 파일을 중앙 집중식으로 저장, 계층형 폴더로 관리, 외부 협업자와 안전하게 공유 및 버전을 복구할 수 있는 클라우드 제어 시스템을 구축한다.

### 1.3 용어 정의

| 용어 | 설명 |
| :--- | :--- |
| 서버사이드 (Server-side) | 서버 측 시스템을 뜻하며, 본 프로젝트에서는 메타데이터 DB와 파일 스토리지 시스템 등을 수행한다. |
| 클라이언트 (Client) | 사용자 눈에 보이는 시스템을 뜻하며, 본 프로젝트에서는 웹 브라우저 기반 UI 시스템을 뜻한다. |
| 활동 로그 | 파일의 업로드, 수정, 다운로드 등 사용자 행동 기록 |
| 버전 제어 | 파일의 변경 이력을 관리하고, 이전 상태로 복원할 수 있는 기능 |
| 블랙박스 테스트 | 시스템 내부 구조를 모르는 상태에서 입력과 출력만으로 기능을 검증하는 테스트 기법 |

## 2. 테스트 개요

### 2.1 테스트 범위
테스트는 시스템 내부를 모른다는 가정 하에 블랙박스 테스트로 이루어진다. 테스트의 범위는 아래와 같다.

| 범위 | 내용 |
| :--- | :--- |
| Web 기반 시스템 | I. 브라우저/서버사이드 동작 정확성 확인<br>II. 요구사항 충족 확인 |
| Database / Storage | I. 사용자/파일/댓글/로그 데이터 입출력 확인<br>II. 공유 링크 만료 처리 확인 |

### 2.2 테스트 항목 및 통과 기준

| 기능별 테스트 항목 | 통과 기준 |
| :--- | :--- |
| 로그인/인증 기능 | 올바른 회원정보만이 로그인에 성공하며 JWT 토큰을 발급받는다. |
| 파일 업로드 기능 | 입력한 파일 정보가 성공적으로 스토리지에 저장 및 출력되며 연동된다. |
| 파일 공유 기능 | 지정된 유효기간 및 권한이 적용된 공유 링크가 정확히 생성되고 동작한다. |
| 파일 다운로드 기능 | 파일 다운로드 처리 | 존재하는 파일은 정상 다운로드되고, 삭제된 파일은 다운로드가 차단된다. |
| 폴더 관리 기능 | 폴더 생성 및 파일 이동 | 폴더가 정상 생성되고 파일이 지정한 폴더로 이동된다. |
| 공유 링크 기능 | 링크 생성 및 만료 처리 | 설정한 유효 시간 내에는 링크로 접근이 가능하고, 만료 후에는 접근이 차단된다. |
| 검색 및 모니터링 기능 | 웹 브라우저에서 동일한 파일 정보를 오류 없이 2초 이내에 출력한다. |
| 댓글 기능 | 댓글 작성/검증 | 정상적인 댓글은 작성자/시간과 함께 저장되고, 공란 댓글은 등록이 차단된다. |
| 활동 로그 기능 | 이벤트 기록 및 필터링 | 업로드/다운로드 이벤트가 실시간으로 기록되고, 파일별 필터링이 정상 동작한다. |
| 버전 관리 기능 | 이전 버전 조회 및 복원 | 버전 목록이 정확히 표시되고, 복원 시 선택한 버전의 내용으로 교체된다. |

| 비기능별 테스트 항목 | 통과 기준 |
| :--- | :--- |
| 브라우저 호환 테스트 | 여러 브라우저(Chrome, Edge 등)에서 웹 시스템이 정상적으로 작동한다. |
| 성능 테스트 | 다중 사용자 접속 시 검색 및 업로드 기능이 성능 저하 없이 작동한다. |
| 보안 테스트 | 로그인하지 않은 사용자가 시스템(파일 접근 등)을 이용할 수 없다. |

## 3. 테스트 케이스

### 3.1 테스트 케이스 선정
테스트 케이스는 본문 2.2의 기능별 테스트 항목에 따라 선정하였으며, 
블랙박스 테스트 기법을 기반으로 하여 시스템 내부 확인을 하지 않는 사용자 시점 테스트 케이스 선정에 중점을 둔다. 

본문 3.3에서 기능별 테스트 케이스 목록을 나열한다.

### 3.2 테스트 케이스 유형
테스트 케이스 유형은 다음과 같다.
* 인증 및 입력을 수행하기 위한 문자열 입력 테스트 케이스
* 버전 관리, 활동 로그 등 **데이터 정합성 확인 테스트 케이스
* 웹 기반 시스템의 동작(파일 업로드/다운로드/검색/공유 등) 확인을 위한 동작 테스트 케이스
* 클라이언트와 서버간의 연동 확인을 위한 데이터 입력 및 확인 테스트 케이스
* 비인가 접근에 대한 보안 테스트 케이스

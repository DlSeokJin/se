(1) 프로젝트 명칭
조직 내 협업 활성화를 위한 클라우드 파일 공유 시스템 구축

(2) 개발 시스템 명칭
미니 드라이브

(3) 개발 시스템에 대한 간단한 설명
사용자는 웹 브라우저를 통해 별도의 설치 없이 다양한 형식의 파일을 중앙 집중식으로 저장, 관리, 다운로드 할 수 있다. 미니 클라우드 이용자들은 서로 파일을 공유할 수 있으며, 파일 검색 기능을 통해 필요한 파일을 빠르게 찾을 수 있다. 미니 클라우드 이용자들은 보안 상 안전함을 보장할 수 있는 환경에서 외부 사용자와 파일 공유가 가능하다.

(4) 개발 시스템에서 제공하는 핵심 기능
1) 중앙 집중식 파일 저장 및 관리
문서, 이미지, 영상 등 다양한 형식의 파일을 웹 브라우저를 통해 업로드하고 다운로드 할 수 있음
업로드는 버튼을 누르고 파일을 선택하는 방식으로 이루어짐
파일의 이름, 업로드 날짜, 파일의 크기와 같은 정보들이 함께 저장됨

2) 계층형 폴더 구조 지원
사용자가 프로젝트별로 폴더를 생성, 수정, 삭제하고 파일을 이동하여 체계적으로 관리할 수 있음

3) 권한 기반 파일 공유
특정 사용자에게 보기, 수정, 댓글 권한을 부여하거나 외부 협업자를 위한 유효기간 설정 공유 링크를 생성할 수 있음

4) 파일 검색 가능
파일 이름을 검색하여 원하는 파일에 접근할 수 있음
'특정 날짜 이후 업로드된 파일', '특정 사용자가 업로드한 파일', '특정 파일 유형' 등으로 원하는 파일을 검색할 수 있음

5) 파일 버전 관리 및 복구
파일이 수정될 때마다 기존 파일을 복사하여 변경사항을 저장함. 이때 기존 파일은 이전 버전 리스트에 저장됨
사용자는 이전 버전을 언제든지 다운로드 받을 수 있으며, 이전 버전으로 복원도 할 수 있음
특정 기간이 지나면 이전 버전은 자동으로 말소됨

6) 사용자 계정 기반 시스템
사용자는 이메일과 비밀번호를 이용하여 로그인 할 수 있음
관리자는 새로운 사용자의 계정을 생성 및 삭제할 수 있으며, 사용자의 저장 공간을 관리함
사용자 그룹을 만들어 부서 별로 저장공간을 공유할 수 있도록 할 수 있음

7) 보안
로그인 인증을 통해 토큰을 받아 특정 파일 위치에 접근할 때마다 접근 가능한 사용자인지 검사함
데이터 전송 시 파일은 자동으로 암호화되어 보안에 기여함

8) 시스템 향상
파일 검색과 다운로드는 빠르게 동작해야 함

9) 확장성
문서 공동 편집 기능
자동 파일 분류 기능
AI 기반 검색 기능
